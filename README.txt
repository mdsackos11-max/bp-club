# Black & Gold Rankings Website

This is a standalone front-end starter inspired by the layout patterns in the reference screenshots/site.

## Run it
Open `index.html` in a browser.

## Customize people
Open `app.js` and edit the `rankings` array:
- `rank`
- `name`
- `title`
- `change`

Replace the placeholder image system in `app.js` with your own image paths, e.g.:
`<img class="photo" src="assets/person1.jpg" alt="Person 1">`

Put your photos inside `assets/`.

## Customize branding
Edit:
- `Prime Rankings` in `index.html`
- `--gold` and `--gold2` in `styles.css`
- hero text, news text, footer, and navigation labels

## Notes
This starter is front-end only. The rankings, countdown, news, voting, members, and profiles are currently demo data. A database/admin dashboard can be connected later so you can manage the rankings without editing code.
